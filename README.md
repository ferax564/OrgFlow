# OrgFlow

Interactive organization-chart and workforce-planning app.

## Features

- Expandable org chart with level presets and search/highlighting
- Position types including heads, team leaders, engineers, graduates and interns
- Approval and hiring-state filters
- Start/end date filtering
- Positions separated from people, including vacant and recruiting roles
- FTE/capacity tracking
- Scenario planning and before/after comparison
- CSV import/export with validation
- Company branding and logo upload
- Light/dark modes and selectable colour palettes, including **Crimson** (red, black and functional grey)
- Branded PNG exports and per-group ZIP exports
- Workspace JSON backup/restore

## Run

Open `index.html` from a web server or GitHub Pages. OrgFlow stores workspace data locally in the browser and does not require a backend.

The deployed build is the same tested single-file application, gzip-compressed and split into static JavaScript chunks so it can be published through the GitHub connector without changing application logic.
