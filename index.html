OrgFlow is an interactive org chart for positions, people and scenarios. Drag a card onto a new manager, undo the last change, then export a board pack or a shareable HTML snapshot — all in the browser you already have open.

How a planning session goes

The landing page is documentation. The planner is app.html. Nothing is posted to a server unless you download a file and send it yourself.

1. Load a shape

First visit opens a tour: Harbor & Co, Northstar Commerce, or a smaller starter (startup, agency, nonprofit). Or start blank.

2. Edit Current or a scenario

Drag a card onto a new manager. Set a dotted line in the drawer. Vacant seats stay on the tree. Create a scenario so Current is untouched.

3. Export what you need

PNG or per-group ZIP for slides. Board-pack PDF for a pack. Shareable HTML that opens without OrgFlow. JSON if you want the workspace back later.

Built for the messy middle of planning

Positions are not people. Vacant seats stay on the chart. Scenarios copy Current instead of overwriting it.

Drag to re-parent

Drop a card onto another manager. Cycles are blocked. The tree updates immediately; Undo puts it back.

Faces and richer cards

Optional local photos, location, cost center and job family on the card and in the position drawer.

Undo and local history

⌘Z or Ctrl+Z for this session. Earlier versions stay in this browser without photos or logos, so storage stays small.

Board-pack PDF

A cover sheet, the current chart, and scenario comparison — generated as a JPEG PDF with no extra library.

Shareable HTML

A self-contained snapshot that opens as a file. The workspace JSON is inside, ready to restore in OrgFlow.

Dotted lines

Matrix reporting is a second manager on the position. It draws dashed; it does not change the tree layout.

Tour and templates

First Light, Lumen Studio and Cedar & Kind sit beside Harbor & Co and Northstar Commerce.

Custom fields

Location, cost center, job family and employee number import and export with the positions CSV.

Private by default

Logos and photos are resized locally. GitHub Pages hosts the program only — not your roster.

In the planner

Filters on the chart do not change Compare. Loading a sample resets chips so a leftover filter cannot hide the new tree.

  • ReportingSolid line = manager on the position. Dashed line = optional dotted-line manager. Drag changes the solid line.
  • PeopleA filled seat has a person. Recruiting and vacant seats have no person record. Unassigning keeps the person in the directory.
  • ScenariosCreate a named copy of Current (or of another scenario). Compare is ID-matched, full snapshots, all dates.
  • DatesThe date filter is off until you turn it on. Future-dated roles stay visible otherwise.
  • BackupWorkspace JSON is the portable copy: every scenario, branding, palette and view. CSV is the active scenario only.

Your roster does not need to leave the laptop.

OrgFlow is static HTML, CSS and JavaScript. GitHub Pages only hosts the program. People names, photos and reporting lines stay in localStorage on this device until you export CSV, JSON, PNG, PDF or HTML.
